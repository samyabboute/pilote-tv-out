# Pilote TV Out

Plateforme de suivi du pilote de rétention TV : saisie des demandes de résiliation par les agents (connexion par TAA), tableau de bord de rétention et administration des utilisateurs.

- `index.html` : l'application
- `config.js` : connexion à la base Supabase (clé publique « anon »)
- `supabase-setup.sql` : installation de la base (à exécuter dans Supabase → SQL Editor)
